Local models cost no money per request, only electricity, which we did not measure. As a rough estimate, assuming
the whole machine draws 400\,W and electricity costs \$0.16/kWh, the GPU time of the main-suite runs comes to about
\$0.006 per correct part for Gemma 4 12B, \$0.002 for the fine-tuned Qwen 4B and \$0.013 for the base Qwen 4B, the
same range as the API models in Fig.~\ref{fig:cost}a. These figures scale directly with both assumptions, so we
leave them out of the figure; build time (Fig.~\ref{fig:cost}b) is the measured cost of running locally.
